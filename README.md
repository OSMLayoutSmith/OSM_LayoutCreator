# OSMTracker Layout Creator

![OSMTracker Layout Creator Interface](https://github.com/user-attachments/assets/5401cc18-66bc-47a3-8450-56f56d6e8106)

A web-based visual tool for creating and customizing layouts for the [OSMTracker](https://github.com/labexp/osmtracker-android) Android application. This project simplifies the layout creation process, allowing users to build complex, multi-language layouts without manually editing XML files.

## ✨ Key Features

* **Visual Editor:** A user-friendly interface with a live phone mockup that previews your layout in real-time.
* **Multi-Language Support:** Easily create and manage button labels and descriptions across multiple languages from a single interface.
* **Subfolder Organization:** Group buttons into pages (subfolders) to create a clean and structured user experience.
* **Full GitHub Integration:**
    * Download and edit existing layouts directly from GitHub repositories.
    * Upload your finished layouts to a GitHub repository to share with the community.
* **Import/Export as .ZIP:**
    * Start a new project by uploading an existing OSMTracker layout `.zip` file.
    * Export your work at any time as a fully compatible `.zip` file, ready for your device.

## 🚀 How to Use

Creating a layout is an easy, five-step process:

1.  **Define Layout Info:** Give your layout a name, a download description, and a README text.
2.  **Add Languages:** Select all the languages you want your layout to support.
3.  **Add Buttons:** Upload a `.png` icon, give the button a name, and add it to the layout.
4.  **Organize & Edit:** Use the "Edit" function to customize button labels for each language or convert buttons into subfolders for better organization.
5.  **Download:** Click "Download Layout as .ZIP" to get your final file.

## 🛠️ Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript
* **Libraries:** [JSZip](https://stuk.github.io/jszip/) for creating and managing `.zip` files.
